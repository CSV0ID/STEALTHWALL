Quality Assurance

Bit-for-Bit Cross-Language Parity

Every statistical feature calculation produces identical floating point numbers across Python and Node.js.

🔢

Half-Up Decimal Rounding

Avoids Python banker's rounding and JavaScript Math.round() quirks via explicit integer scaling (floor(v * 10^d + 0.5) / 10^d).

🔤

Zero-Regex Normalization

Python re and JS RegExp disagree on Unicode character classes. Normalization in STEALTHWALL uses deterministic character code loops.

🧪

Automated Parity CI Gate

Every git commit re-runs 11 seeded attack corpora through both engines. CI fails immediately if floating-point discrepancy exceeds 5e-8.
