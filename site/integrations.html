Universal Middleware & Edge Support

Integrate in 60 Seconds with 1 Line of Code

Native SDKs and drop-in reverse proxy handlers for every modern web language and infrastructure stack.

# 1. Install from PyPI
pip install stealthwall

# 2. Add to your FastAPI app
from fastapi import FastAPI
from stealthwall import StealthWall

app = FastAPI()
StealthWall(app)  # That's it! Full ML WAF & kernel protection is now active.

@app.get("/api/data")
def get_data():
    return {"status": "secure"}

Supported Stacks & Environments

Zero architectural changes required. Deploy as an in-process middleware or an autonomous sidecar.

🐍

Python / FastAPI / Starlette

Pure ASGI asynchronous middleware running in-process. Evaluates sliding-window entropy per request and coordinates with local kernel iptables.

🟢

Node.js / Express.js

Official npm package (npm i stealthwall). Communicates with the local ONNX inference engine with sub-millisecond DecisionClient RPC.

▲

Next.js Edge Middleware

Deploy on Vercel or Netlify Edge. Protects App Router and Pages Router routes right at the global CDN edge before server components render.

🐘

PHP & WordPress

Drop-in single-file include (integrations/php/stealthwall.php) inside wp-config.php or root index for legacy PHP 7.4 - 8.3 stacks.

⚡

Nginx Reverse Proxy

Universal auth_request subrequest configuration protecting any backend (Go, Rust, Ruby, Java, C#) without touching source code.

🐳

Docker & Kubernetes

1-Click containerized deployment with Redis state clustering, Prometheus scrapers, and Grafana telemetry dashboards.
